Everything you need to block out motion

No graph editors, no dope sheets to learn. Pose, move along the timeline, pose again.

Pose by dragging

Every bone has a handle at its tip — drag it and the bone swings, like Pivot. The orange square moves the whole rig; gizmos are there for precise turns.

Your rig's IK

Limbs driven by Blender IK are posed by dragging the hand or foot, with poles aiming the elbow and knee — matching Blender's solver to within half a degree.

Onion skin

See the previous and next poses as coloured ghosts while you work, or every Nth frame, so spacing is easy to judge — and pin a ghost of the first frame to keep the starting pose in view.

A clear timeline

One row of pose keys, one row for where the selected bone moves. Drag to retime, box-select, set easing, and loop just the part you're polishing.

Snapping

From the side, front or top, handles land on a grid and bones swing in clean angle steps — measured in Blender units.

Cycles and reference

Mirror a pose, or key its mirror half a cycle later for walks. Pose against a reference image or a video that follows the playhead.

Your .blend stays yours

MeshAnimate reads and writes .blend files through Blender itself, and treats them carefully.

  • Backed up first. Every save copies the file to .meshanimate-backups/ beside it; the newest 20 are kept.
  • Only what you changed. Untouched actions are left as they were; in an edited action, bones you didn't touch keep Blender's original curves.
  • Proper Blender actions. New animations get a fake user and their own NLA track; renaming a clip renames its track.
  • Plays like Blender. Untouched actions preview Blender's own evaluation; edits use the same Bézier, easing and quaternion maths, checked against Blender in the test suite.
  • Notices outside changes. Save the file from Blender while it's open here and MeshAnimate reloads it — or, with unsaved work, offers to merge.
Rigs that drive their mesh through other constraints — Rigify's Copy Transforms, Stretch To and drivers, for example — can be animated and saved, but the viewport preview is only approximate for them. MeshAnimate tells you when it opens one.

Requirements & building

You need Blender installed (tested with 5.2); MeshAnimate finds it automatically or you can point to it in Preferences. Your .blend needs an armature — skinned meshes and rigid parts parented to bones both work. 

bun install          # or npm install
bun run dev          # run with hot reload
bun run test         # unit tests, including Blender parity fixtures
bun run build:linux  # or build:win / build:mac
